# AFL_AUTOS_PUBLIC

Capa pública de AFL Autos.

## Alcance
Este repositorio contiene únicamente información apta para publicación: inventario comercial sanitizado y la interfaz pública.

## No publicar aquí
- VIN completo.
- URLs o IDs privados de Google Drive.
- Checkpoints y estados operativos internos.
- Prompts, reglas administrativas o archivos de sistema.
- Datos privados de clientes o leads.

Fuente operativa: repositorios privados de AFL Autos. Este repositorio funciona como proyección pública sanitizada.
